# 天意宇宙 · 新三国梗星图 ⭐

> 把《新三国》(2010) 的吐槽梗做成一张可交互的**深空星图**：每颗星 = 一个梗，点击播放原片语音/视频片段；梗与梗之间的连线是"天意"的关系网。

**🌐 在线玩**: https://sanqipanax.github.io/tianyi-universe/

**83 个梗节点 · 62 条关系线 · 81 个已剪辑素材 · 95 集台词全文索引**

## ✨ 特性

- 🌌 **星图交互**：D3 force-directed，拖拽/缩放/漫游自动巡星
- 🎵 **点击即听**：每个有素材的节点（绿虚线环）可播放原片台词片段
- 🕸️ **关系网络**：8 种连线（回旋镖/互文/天意修正/兼用卡/演员联动/原著对比/权谋因果/二创回授）
- 🔥 按出圈度/是否 R9 二创捧红筛选
- 🔍 **网页台词搜索框**：输入台词/梗名/演员 → 同时命中梗节点（聚焦星体+开档案）与原片台词（定位到集+秒播放，需本地有源片）
- 📇 **95 集台词全文索引**：Whisper 转写的逐句带时间戳文本（`tools/whisper_out/`），另有 80k 行网页内索引 `data/script_index.js`

## 🎮 运行

线上版(GitHub Pages)含全部 81 个可播片段,直接打开即玩;**本地增强版**可额外解锁"搜台词→整集定位播放"：

1. 下载 2010 版《三国》(XTM 等版本均可) 放入 `新三国/新三国NN.mkv`
2. 用 `tools/` 下的工具裁剪片段到 `clips/{梗id}.mp3/.mp4`（命名 = `data/nodes.js` 中的节点 id）
3. 浏览器打开 `index.html`（file:// 直接可用,搜台词点结果可从源片对应秒播放）

> 想看全貌也可以先不裁剪——打开页面即见 83 颗星与关系网，只是部分节点无音频。

## 🛠️ 工具链

定位一句台词在哪一集哪一秒（旧方案 OCR 已废弃，现用 Whisper）：

```bash
# 跨 95 集搜台词（支持容错词）
node tools/25_whisper_search.js 天意 骄兵 换大盏

# 单集转写 / 全量断点续跑（GPU: faster-whisper medium）
python tools/20_whisper_scan.py 36
python tools/26_whisper_all.py 1 95

# 多段拼一个集锦 clip（机制类梗用）
node tools/27_concat.js tiyi '[{"ep":34,"start":199,"end":214},...]'

# 数据健康报告 / clip 校准 / 网页台词索引
node tools/report.js
node tools/28_verify_clips.js
node tools/gen_script_index.js
```

## ⚠️ 说明

- 梗与剪辑灵感来自 B 站 UP 主们（折棒/R9 等）的吐槽文化；台词文本为自动语音转写，可能有同音字误差
- 2 个梗（鲁肃"我也是醉了"为网友二创套梗、文/武关羽替身为全剧跨集现象）无独立原句，已标 `noCut` 展示不剪
- 本仓库**不含整集视频**（33GB 源片 `新三国/` 版权不入库）；`clips/` 内为各梗数秒~数十秒的短片段（网络吐槽文化常见的短引用），在线可试听/观看；如版权方认为不妥请联系删除
