# 天意宇宙 · 新三国梗星图 ⭐

> 把《新三国》(2010) 的吐槽梗做成一张可交互的**古星图**：每颗星 = 一个梗，点击播放原片语音/视频片段；梗与梗之间的连线是"天意"的关系网。

**🌐 在线玩**: https://sanqipanax.github.io/tianyi-universe/

**83 个梗节点 · 62 条天意线 · 81 个已剪辑素材 · 95 集台词全文索引**

## ✨ 特性

### 视觉：借古星官的皮

整体参照中国古星图（敦煌星图 / 苏州石刻天文图）的视觉语言，配色取矿物颜料朱砂 / 石青 / 藤黄 / 赭石 / 月白：

| 势力 | 星官分组 | 色 |
|---|---|---|
| 魏·曹操系 | 紫微垣（中宫帝座） | 藤黄 |
| 蜀·刘备系 | 太微垣（汉室朝堂） | 朱砂 |
| 吴·孙权系 | 天市垣（四方市井） | 石青 |
| 群像·其他 | 二十八宿 | 紫草 |
| 天意机制 | 客星（异象） | 月白 |
| 服化道/拍摄 | 荧惑 | 苍墨 |
| 演员/幕后 | 杂星 | 赭石 |

> ⚠️ 分组是**借古星官之名做视觉分类，非史实对应**（图例已标注）。

- 🌌 中心「天意」是一枚黑盘金边的帝星，三环反向旋转 + 呼吸脉动
- 星图外围是二十八宿刻度环，宿名随缩放淡入
- 节点为矿物色星体（径向渐变 + 独立辉光层），有素材的加绿虚线圈
- 星空分三层视差 + 平滑呼吸 + 偶发流星，随缩放产生纵深

### 交互：丝滑与反应

- 🎥 **镜头语言**：进入时先贴近中宫、再缓缓拉开给全貌；点星体只在它跑到画面边缘时才挪镜头
- 🌊 **涟漪传播**：点任意星体，天意自中宫沿关系网一路点亮过去
- ✨ **光点流动**：悬浮/选中某星体时，与它相关的连线亮起并有光点沿曲线流动，其余压暗
- 🏷️ **标签避让**：按出圈度优先级贪心排布，压在一起的自动隐去；字号随缩放反向补偿，任何倍率下都清晰
- 🎬 **播片模式**（按 `H`）：隐藏全部界面 + 自动巡游高光节点 + 自动播原片台词 + 底部字幕条 —— **专为录屏出片设计**
- 🎵 **主页 BGM「关羽之歌」**：进入宇宙即循环（**32 秒**，音量 0.34），**一旦开始播某个梗的原片片段就自动让出声道**，片段播完或关掉播放器后自动续上；播片模式下全程不叠 BGM。右上角 🔊 按钮可关，选择记在 `localStorage`；切到别的标签页会自动静音、回来续播

  > 这 32 秒是**用音频指纹在全剧里标定出来的**，不是随手截的。详见 `tools/29_bgm_scan.py` 与 `tools/30_bgm_build.py`：拿 ep34 197-213s（现有素材出处）当模板，用 Shazam 式地标指纹在全 95 集里做匹配，再用滑动追踪量出这次演奏的连续长度 —— 结论是**这首曲子本身约 32 秒**（ep34 197-229s），全剧 25+ 处使用用的都是同一段，没有更多素材可拼。素材缺失时页面会自动回退到旧的 16 秒片段。
- 🔍 网页台词搜索框：输入台词/梗名/演员 → 同时命中梗节点（聚焦星体 + 开档案）与原片台词（定位到集 + 秒播放，需本地有源片）

## 🎮 运行

线上版(GitHub Pages)含全部 81 个可播片段，直接打开即玩；**本地增强版**可额外解锁"搜台词 → 整集定位播放"：

1. 下载 2010 版《三国》(XTM 等版本均可) 放入 `新三国/新三国NN.mkv`
2. 用 `tools/` 下的工具裁剪片段到 `clips/{梗id}.mp3/.mp4`（命名 = `data/nodes.js` 中的节点 id）
3. 浏览器打开 `index.html`（file:// 直接可用，搜台词点结果可从源片对应秒播放）

> 想看全貌也可以先不裁剪——打开页面即见 83 颗星与关系网，只是部分节点无音频。

### 快捷键

| 键 | 作用 |
|---|---|
| `H` | 播片模式（隐藏界面 + 自动巡游 + 字幕） |
| `空格` | 漫游开/关 |
| `F` | 全览星图 |
| `R` | 复位视角并解锁被拖动的星体 |
| `Esc` | 关面板 / 退出播片 |

> 右上角 🔊 = 关羽之歌 BGM 开关（默认开，选择会被记住）。浏览器要求先有用户手势，所以 BGM 是在点「进入宇宙」那一刻起播的。

## 🛠️ 工具链

定位一句台词在哪一集哪一秒（旧方案 OCR 已废弃，现用 Whisper）：

```bash
# 跨 95 集搜台词（支持容错词）
node tools/25_whisper_search.js 天意 骄兵 换大盏

# 单集转写 / 全量断点续跑（GPU: faster-whisper medium）
python tools/20_whisper_scan.py 36
python tools/26_whisper_all.py 1 95

# 多段拼一个集锦 clip（机制类梗用）
node tools/27_concat.js tiyi '[{"ep":34,"start":199,"end":214},...]'

# 数据健康报告 / clip 校准 / 网页台词索引
node tools/report.js
node tools/28_verify_clips.js
node tools/gen_script_index.js
```

定位/生成 BGM 的音频指纹工具（纯音乐台词索引抓不到，只能靠音高与频谱指纹）：

```bash
# 在全剧里找「关羽之歌」（地标指纹,Shazam 式;chroma 已实测不可用）
python tools/29_bgm_scan.py scan                      # 全 95 集
python tools/29_bgm_scan.py scan --eps 34 35 --ref 197 209   # 小样本 / 换模板
python tools/29_bgm_scan.py probe --probe-ep 34 --at 197     # 量某次演奏的连续长度

# 拼 BGM（读扫描结果,交叉淡化 + 统一响度）
python tools/30_bgm_build.py --want 75
python tools/30_bgm_build.py --single 34:197:32       # 单段长镜头
```

> ⚠️ 该工具踩过两个坑，都已修并写在文件头注释里：①参考切片起点必须**对齐到 hop 整数倍**（否则同一段音频也提不出同一批峰，自匹配率 92%→32%）；②哈希 key 在参考里重复时 `searchsorted` 只取第一条，长参考下会把偏移直方图打散（必须展开所有重复项）。

梗雷达（半自动发现圈内新梗）见 `tools/radar/`，用法与结论在 `tools/radar/report_*.md`。

## ⚠️ 说明

- 梗与剪辑灵感来自 B 站 UP 主们（折棒/R9 等）的吐槽文化；台词文本为自动语音转写，可能有同音字误差

- 本仓库**不含整集视频**（33GB 源片 `新三国/` 版权不入库）；`clips/` 内为各梗数秒~数十秒的短片段（网络吐槽文化常见的短引用），在线可试听/观看；如版权方认为不妥请联系删除
