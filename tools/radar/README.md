# 天意宇宙 · 梗雷达 (B站 新三国圈 热门新梗自动扫描)

> 半自动流水线第 ①~⑤ 步的落地实现:机器扫描 → 出候选报告 → **人工逐条确认后才入库**。
> 铁律:第 ⑥ 步人工确认必须保留(全自动一周后 = 40 个垃圾梗,星图变浆糊)。

## 流水线对应

| 方案步 | 实现 | 文件 |
|---|---|---|
| ① B站信号层 | wbi签名搜索 + pagelist + seg.so 弹幕(protobuf) | `bili_api.py` |
| ② 候选提取 | 弹幕高频句 × 跨视频复现计数 | `radar_scan.py` |
| ③ 热度门槛 | 跨≥2视频(短句≥3) 总次数≥3, 可调 | `radar_scan.py` |
| ④ 原句考证 | 95集 whisper 模糊匹配(容错错字) | `whisper_index.py` |
| ⑤ 查重 | 与 data/nodes.js 83 节点 bigram 相似度 | `nodes_ref.py` |
| ⑥ 入库 | ❌ 不自动, 人工读报告确认 | —(本工具止步于报告) |

## 用法

```bash
# 完整扫描(默认近30天发布内容, 抓前14个视频弹幕, 每视频≤30段)
python radar_scan.py

# 常用调参
python radar_scan.py --days 14 --top 10 --max-seg 12 --out report_20260909

# 只列视频池不抓弹幕(调试信号层)
python radar_scan.py --no-danmaku
```

输出:
- `report_YYYYMMDD.md` 候选报告(分 A 疑似新梗 / A2 泛用口语 / B 疑似二创 / C 已有梗热度)
- `report_YYYYMMDD.json` 结构化候选池(未来给"确认页"用)

## 考证口径

- `✅ strong`:候选句在原片有强命中(≥1锚点+覆盖率≥0.5),可信为原片台词
- `⚠️ weak`:只靠 bigram 覆盖率命中,whisper 错字/断句导致,提示存在但需人工复核
- `❌` 未检索到:95 集 whisper 全文无近似 → **疑似纯二创/空耳/新编**(参照 lushu-zuile 案例:不能入库当原句)
- `泛用 N 集`:该句在原片 ≥N 集出现 → 通用对白,单点成梗概率低

## 反爬纪律

- 沙箱 schannel 无凭据 → 一律 python 走代理 `127.0.0.1:7897`(PROXY 可环境变量覆盖)
- 内置 0.45-0.6s 请求间隔;**别高频连跑**,同一天多轮扫描可能触发 -412
- -412 时等几分钟再跑,或提高 `--min-dm`/`--top` 让单轮请求更少

## 已知边界

1. whisper 转写错字多(如"何进"→"郭靖"),强命中偏保守;弱命中段要人工
2. 弹幕只取前 N 段(seg.so 每 180s 一段),超长合集是抽样非全量
3. 未接入热门评论 API(x/v2/reply),目前只用弹幕层
4. "热度≠梗":跨视频复现只是信号,是否够格入库靠人对圈内语境的判断
